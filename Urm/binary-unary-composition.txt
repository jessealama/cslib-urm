Proof of closure of binary URM-compatible functions with unary URM-computable functions:

Let F, G1 and G2 be the URM programs computing f, g1 and g2, respectively. we can assume that each are in standard form.

How would the computation go? Let m be the max of the registers referred to be F, G1, and G2. We'll have a couple regions of registers:

* Active registers: R[0] ... R[m] (F, G1, and G2 refer to these registers and nothing beyond m)
* Copy of initial input: R[m + 1] (only one since the gs are unary)
* Scratch region/registers: R[m + 2], R[m + 3] (two, since f is binary)
* The rest: R[m + 4], ... don't matter what values these contain because they are never used by any program, nor the one we're about to construct

The constructed program:

- copy R[0] to R[m + 1]
- run G1
- copy R[0] to R[m + 2]
- copy R[m + 1] to R[0]
- run G2
- copy R[0] to R[m + 3]
- copy R[m + 2] to R[0]
- copy R[m + 3] to R[1]
- run F

This could be understood as a concatenation of:

1. (copy initial arguments)
2. G1
3. (save to first scratch register)
4. (restore initial arguments)
5. G2
6. (save to second scratch register)
7. (convert scratch region to initial arguments)
8. F

We want to show that H computes f(g1, g2): for all natural numbers x and y,

    H terminates with input argument x with value y in R[0]
        iff
    (1) x is in dom g1,
    (2) x is in dom g2,
    (3) the pair (g1(x), g2(x)) is in dom f, and
    (4) y = f(g1(x), g2(X)).

Here are a few lemmas I might see worth formulating:

* the program consisting of the first three "steps" of H (1, 2, and 3) is computationally equivalent to g1
* the program consisting of "copy R[m + 1] to R[0], then run G2" computes g2 on R[m + 1]
* (continuing on that lemma immediately above), the program "copy R[m + 2] to R[0], copy R[m + 3] to R[1], run F" computes f on R[m + 2] and R[m + 3].
