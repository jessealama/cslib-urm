Theorem 3.1: Suppose that f(y_{0}, ..., y_{k}) and g_{0}(x), ..., g_{k}(x) are computable functions where x = (x_{0}, ..., x_{n}). Then the function h(x) given by h(x) = f(g_{0}(x), ... , g_{k}(x)) is computable.

(Note: h(x) is defined if and only if g_{0}(x), ... , g_{k}(x) are all defined and (g_{0}(x), ... , g_{k}(x)) \in Dom(f); thus, if f and g_{0}, ... , g_{k} are all total functions, then h is total.)

Proof: Suppose that F, G_{0}, ... , G_{k} are programs in standard form which compute f, g_{0}, ... , g_{k}, respectively. We will write a program H which that embodies the following natural procedure for computing h: "Given x, use the programs G_{0}, ... , G_{k} to compute in succession g_{0}(x), ... , g_{k}(x), making a note of these values as they are obtained. Then use the program F to compute f(g_{0}(x), ... , g_{k}(x))."

We must take a little care to avoid losing information needed at later stages in the procedure, namely x and those values g_{i}(x) already obtained. Putting m = max(n, k, F.maxRegister, G_{0}.maxRegister, ... , G_{k}.maxRegister), we shall begin by storing x in R_{m} + 1, ... , R_{m + n}; the register R_{m + n + 1}, ... , R_{m + n + k} will be used to store the values g_{i}(x) as they are computed for i = 0, 1, ..., k. These registers are completely ignored by computations under F, G_{0}, ..., G_{k}. A typical configuration during the computation under H will be

| R_{0}, ... , R_{m} | R_{m + 1}, ... , R_{m + n} | R_{m + n + 1} | R_{m + n + 2} | ... | R_{m + n + k} | .... |
|--------------------|-----------------------------|--------------|---------------|-----|---------------|------|
| ...                | x                           | g_{0}(x)     | g_{1}(x)      | ... | g_{k}(x)      | 0    |
----------------------------------------------------------------------------------------------------------------

This is easily translated into the following program H that computes h:

T(0, m)
.
.
.
T(n, m + n)
G_{1}[m, m + 1, ... , m + n --> m + n + 1] (this is the notation where we shift all registers used in a program and save the final result to register m + n + 1)
.
.
.
G_{k}[m, m + 1, ... , m + n --> m + n + k] (again repeating the notation)
F[m + n + 1, ... , m + n + k --> 0]

Clearly a computation H(x) will stop if and only if each computation G_{i}(x) stops (0 <= i <= k) and the computation F(g_{0}(x), ... , g_{k}(x)) stops, which is exactly as required.
